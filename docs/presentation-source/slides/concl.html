Conclusion

The system transfers files over TCP sockets with confidentiality, integrity and authentication, using AES for encryption, RSA for key exchange and SHA-256 for verification.

Future work: digital signatures, TLS integration, resume support for interrupted transfers, and a graphical drag-and-drop interface.
