Existing System

Common file sharing relies on plain FTP, HTTP, email attachments or cloud services. FTP and basic socket programs transmit data without encryption.

Secure options such as SFTP, SCP and HTTPS exist, but they hide the details inside large libraries, so students and small users cannot easily see or customize how keys, encryption and verification work.

Many simple implementations also skip integrity checks and authentication.
