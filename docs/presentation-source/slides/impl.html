Implementation

1. Data Input

Choose file, server IP and port.

2. Connection

TCP socket connect and accept.

3. Key Exchange

RSA public key shared, AES key sent encrypted.

4. Hashing

SHA-256 digest of the original file.

5. Encryption

AES-GCM with a fresh nonce per file.

6. Transfer

Encrypted chunks sent over the socket.

7. Verification

Decrypt, recompute hash and compare.

8. Output

Saved file with success or failure message.
