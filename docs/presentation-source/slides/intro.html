Introduction

Files such as documents, reports and source code are shared across networks every day. Plain protocols like FTP send data and passwords in clear text, so anyone on the path can read or change them.

This project uses Python socket programming over TCP for reliable client-server communication, and applies hybrid cryptography: AES for fast file encryption and RSA for safe key exchange.

A SHA-256 digest is sent with each file so the receiver can detect any modification or corruption.
