Objectives

1. Secure Communication

Build a TCP client-server using socket programming.

2. Confidentiality

Encrypt files with AES before transmission.

3. Safe Key Exchange

Share session keys using RSA public-key encryption.

4. Integrity

Verify every file with a SHA-256 hash.

5. Authentication

Allow only authorized clients using login or key checks.

6. Practical Use

Support files of any type and size with chunked transfer.
