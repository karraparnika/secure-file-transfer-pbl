Proposed System

A client-server application that transfers files securely over TCP sockets using hybrid cryptography.

The server generates an RSA key pair and shares its public key. The client creates a random AES session key, encrypts it with the RSA public key and sends it. The file is then encrypted with AES-GCM and sent in chunks.

The receiver decrypts the file and verifies its SHA-256 hash. Any mismatch rejects the file. A simple interface shows transfer status and verification results.
